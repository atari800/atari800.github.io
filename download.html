Download

Official Releases

Atari800 source code and binary packages are on GitHub releases.

Binary packages typically take a few days to be built and uploaded, so please check back occasionally or follow the announcements on our mailing list.

Atari800 for Android is named Colleen and is available on Google Play.

Colleen's Help Page is right here and is continually updated.


Linux distributions

deb

Debian, Ubuntu and derived distributions can install atari800 package directly from their official repositories: 

apt install atari800
It's often outdated, though - that's why we distribute our own .deb package.

rpm

In Fedora the atari800 package is just one command away: 

dnf install atari800
Other Fedora based/derived/related distros need to enable EPEL first.
